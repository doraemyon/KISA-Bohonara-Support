Title:
Debian and Ubuntu Package Manager APT Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Debian and Ubuntu Package Manager APT Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o A vulnerability was discovered in the package manager (APT) used to install or update application SW in the Linux operating system. [1] ~ [4]
※ APT (Advanced Packaging Tool): Linux package manager that performs application installation, updates, and upgrades.
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o UNIX Hard Link Vulnerability Caused by APT (CVE-2026-109518) [1] ~ [5]
