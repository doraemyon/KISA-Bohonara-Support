제목:
SAP 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "SAP 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o SAP社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[5]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o SAP NetWeaver AS ABAP and ABAP Platform (SAML2 Service Provider)에서 발생하는 Improper Verification of Cryptographic Signature 취약점(CVE-2026-120017) [1][2][6]
o SAP NetWeaver AS ABAP (Internet Communication Manager)에서 발생하는 Improper Validation of Specified Type of Input 취약점(CVE-2026-76964) [1][3][7]
o SAP Web Dispatcher에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-89126) [1][4][8]
o SAP Gateway에서 발생하는 Incorrect Authorization 취약점(CVE-2026-89103) [1][5][9]

□ 영향을 받는 제품 및 해결 방안
