Title:
SAP Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "SAP Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o SAP releases security updates to address vulnerabilities in its products [1]~[5]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Improper Verification of Cryptographic Signature vulnerability in SAP NetWeaver AS ABAP and ABAP Platform (SAML2 Service Provider)(CVE-2026-120017) [1][2][6]
o Improper Validation of Specified Type of Input vulnerability in SAP NetWeaver AS ABAP (Internet Communication Manager)(CVE-2026-76964) [1][3][7]
o Heap-based Buffer Overflow Vulnerability in SAP Web Dispatcher (CVE-2026-89126) [1][4][8]
o Incorrect Authorization vulnerability in SAP Gateway (CVE-2026-89103) [1][5][9]
