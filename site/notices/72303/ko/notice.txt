제목:
WordPress 플러그인 보안 업데이트 권고

요약:
금일 KISA 공지 "WordPress 플러그인 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o WordPress의 WPML Multilingual CMS 플러그인에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[4]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o WPML Multilingual CMS에서 발생하는 Improper Authentication 취약점(CVE-2026-76877) [1][5]
o LiteSpeed Cache에서 발생하는 Exposure of Sensitive Information to an Unauthorized Actor 취약점(CVE-2026-93389) [2][6]
o Elementor Website Builder에서 발생하는 Cross-site Scripting 취약점(CVE-2026-109883) [3][7]
o Ninja Forms - File Uploads에서 발생하는 Path Traversal 취약점(CVE-2026-126537) [4][8]

□ 영향을 받는 제품 및 해결 방안

취약점 / 제품명 / 영향받는 버전 / 해결 버전
CVE-2026-76877 / WPML Multilingual CMS / 4.9.7 이하 / 5.0.0 이상
CVE-2026-93389 / LiteSpeed Cache / 7.9.1 이하 / 7.9.2 이상
CVE-2026-109883 / Elementor Website Builder / 4.3.5 이하 / 4.3.6 이상
CVE-2026-126537 / Ninja Forms - File Uploads / 3.3.36 이하 / 3.3.37 이상

※ 하단의 참고 사이트를 확인하여 업데이트 수행 [1]~[4]
