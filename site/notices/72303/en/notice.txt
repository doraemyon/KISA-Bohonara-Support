Title:
WordPress plugin security update advisory

Summary:
We are disseminating today's KISA announcement "WordPress plugin security update advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Announced security update that addresses vulnerabilities in the WPML Multilingual CMS plugin for WordPress [1]~[4]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Improper Authentication vulnerability occurring in WPML Multilingual CMS (CVE-2026-76877) [1][5]
o Exposure of Sensitive Information to an Unauthorized Actor vulnerability occurring in LiteSpeed ​​Cache (CVE-2026-93389) [2][6]
o Cross-site Scripting vulnerability occurring in Elementor Website Builder (CVE-2026-109883) [3][7]
o Ninja Forms - Path Traversal Vulnerability Occurring in File Uploads (CVE-2026-126537) [4][8]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-76877 / WPML Multilingual CMS / 4.9.7 or earlier / 5.0.0 or later
CVE-2026-93389 / LiteSpeed Cache / 7.9.1 or earlier / 7.9.2 or later
CVE-2026-109883 / Elementor Website Builder / 4.3.5 or earlier / 4.3.6 or later
CVE-2026-126537 / Ninja Forms - File Uploads / 3.3.36 or earlier / 3.3.37 or later
※ Check the reference site below to perform updates [1]~[4]
