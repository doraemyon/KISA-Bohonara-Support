Title:
Apache Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Apache Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Apache Foundation announces security update that addresses vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Race Condition Vulnerability in Apache HTTP Server (CVE-2026-119618) [1][2]
o NULL Pointer Dereference vulnerability in Apache HTTP Server (CVE-2026-106023) [1][3]
o Stack-based Buffer Overflow vulnerability occurring in Apache HTTP Server (CVE-2026-109163) [1][4]

□ Affected Products and Solutions

Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-119618 / Apache HTTP Server / 2.4.55 or later and below 2.4.71 / 2.4.71 or later
CVE-2026-106023 / Apache HTTP Server / 2.4.30 or later and below 2.4.71 / 2.4.71 or later
CVE-2026-109163 / Apache HTTP Server / 2.4.69 or later and below 2.4.71 / 2.4.71 or later

※ Check the reference site below to perform updates [1]
