Title:
BeyondTrust Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "BeyondTrust Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o BeyondTrust releases security updates to address vulnerabilities in its products. [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Authentication Bypass by Spoofing Vulnerability in BeyondTrust Remote Support (CVE-2026-102764) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-102764 / Remote Support / 26.2.3 or earlier / 26.3.1 or later
※ Perform updates by referring to the sites listed below. [1]
