Title:
Ahsay Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Ahsay Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Ahsay released security updates addressing vulnerabilities in its products [1]
o Users operating affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Improper Authentication vulnerability in AhsayCBS (CVE-2026-105133) [1][2]
o OS Command Injection vulnerability in AhsayCBS (CVE-2026-105134) [1][3]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-105133 / AhsayCBS / Below 9.15.2.70 / 9.15.2.70 or higher
CVE-2026-105133 / AhsayCBS / Below 10.3.4.45 / 10.3.4.45 or higher
CVE-2026-105134 / AhsayCBS / Below 9.15.2.70 / 9.15.2.70 or higher
CVE-2026-105134 / AhsayCBS / Below 10.3.4.45 / 10.3.4.45 or higher
