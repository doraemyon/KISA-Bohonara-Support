Title:
Cisco Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Cisco Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Cisco releases security updates to address vulnerabilities in its products [1]~[3]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Use of Hard-coded Credentials Vulnerability in Cisco Expressway (CVE-2026-76466) [1][4]
o Out-of-bounds Write Vulnerability in Cisco Expressway (CVE-2026-76490) [2][5]
o Reachable Assertion Vulnerability in Cisco Expressway (CVE-2026-76491) [2][6]
o NULL Pointer Dereference Vulnerability in Cisco Expressway (CVE-2026-76492) [2][7]
o Uncaught Exception Vulnerability in Cisco Expressway (CVE-2026-76493) [2][8]
o Code Injection Vulnerability in Cisco Expressway (CVE-2026-76494) [2][9]
o Incorrect Permission Assignment for Critical Resource vulnerability in Cisco Expressway (CVE-2026-76495) [2][10]
o Link Following Vulnerability in Cisco Expressway (CVE-2026-76496) [2][11]
o Injection vulnerabilities in Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, and Unity Connection (CVE-2026-76473) [3][12]
o Improper Authentication Vulnerability in Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, and Unity Connection (CVE-2026-76474) [3][13]
o Cross-site Scripting Vulnerability in Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, and Unity Connection (CVE-2026-76475) [3][14]
o Improper Input Validation vulnerability in Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, and Unity Connection (CVE-2026-76476) [3][15]
o SQL Injection vulnerabilities in Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, and Unity Connection (CVE-2026-76477) [3][16]
o Improper Access Control Vulnerability in Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, and Unity Connection (CVE-2026-76478) [3][17]
o Path Traversal vulnerability in Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, and Unity Connection (CVE-2026-76479) [3][18]
o Improper Check or Handling of Exceptional Conditions vulnerability in Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, and Unity Connection (CVE-2026-76481) [3][19]
