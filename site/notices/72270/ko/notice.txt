제목:
Apache 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Apache 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Apache 재단은 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[8]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고
□ 설명
o Apache Fineract에서 발생하는 SQL Injection 취약점(CVE-2026-64618) [1][9]
o Apache Fineract에서 발생하는 SQL Injection 취약점(CVE-2026-65874) [2][10]
o Apache Tomcat에서 발생하는 Time-of-check Time-of-use (TOCTOU) Race Condition 취약점(CVE-2026-80353) [3][11]
o Apache Tomcat에서 발생하는 Incomplete Cleanup 취약점(CVE-2026-88041) [4][12]
o Apache Tomcat에서 발생하는 Incomplete Cleanup 취약점(CVE-2026-93446) [5][13]
o Apache Tomcat에서 발생하는 Missing Critical Step in Authentication 취약점(CVE-2026-101296) [6][14]
o Apache Tomcat에서 발생하는 Race Condition 취약점(CVE-2026-101356) [7][15]
o Apache Tomcat에서 발생하는 Buffer Under-read 취약점(CVE-2026-103119) [8][16]
