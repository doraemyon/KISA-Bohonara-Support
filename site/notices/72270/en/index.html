Title:
Apache Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Apache Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o Apache Foundation announces security update that addresses vulnerabilities in its products [1]~[8]
o Users using the affected version are advised to update to the latest version as per the resolution.
□ Description
o SQL Injection vulnerability occurring in Apache Fineract (CVE-2026-64618) [1][9]
o SQL Injection vulnerability occurring in Apache Fineract (CVE-2026-65874) [2][10]
o Time-of-check Time-of-use (TOCTOU) Race Condition vulnerability in Apache Tomcat (CVE-2026-80353) [3][11]
o Incomplete Cleanup vulnerability in Apache Tomcat (CVE-2026-88041) [4][12]
o Incomplete Cleanup vulnerability in Apache Tomcat (CVE-2026-93446) [5][13]
o Missing Critical Step in Authentication vulnerability occurring in Apache Tomcat (CVE-2026-101296) [6][14]
o Race Condition Vulnerability Occurring in Apache Tomcat (CVE-2026-101356) [7][15]
o Buffer Under-read Vulnerability Occurring in Apache Tomcat (CVE-2026-103119) [8][16]
