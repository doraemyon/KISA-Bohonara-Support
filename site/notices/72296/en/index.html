Title:
MongoDB Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "MongoDB Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o MongoDB announces security updates that address vulnerabilities in its products [1]
o Users with affected versions are advised to update to the latest version as a workaround
