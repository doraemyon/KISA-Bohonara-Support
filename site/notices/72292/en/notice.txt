Title:
SonicWall Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "SonicWall Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
Course Overview
o SonicWall announces a security update that addresses vulnerabilities in its products [1]
o Users with affected versions are advised to update to the latest version as a workaround

Description
o Heap-based Buffer Overflow Vulnerability in SonicOS (CVE-2026-82308) [1] [2]
o Reliance on IP Address for Authentication vulnerability in SonicOS (CVE-2026-107154) [1] [3]
o Permissive Cross-domain Security Policy with Untrusted Domains Vulnerability on SonicOS (CVE-2026-107155) [1] [4]
