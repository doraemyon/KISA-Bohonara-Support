Title:
Apache Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Apache Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o The Apache Foundation released security updates to address vulnerabilities in their products [1]~[10]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Improper Authentication vulnerability in Apache Tomcat(CVE-2026-68569) [1][11]
o Incorrect Authorization vulnerability in Apache Tomcat(CVE-2026-68525) [2][12]
o Uncontrolled Resource Consumption vulnerability in Apache Tomcat(CVE-2026-66299) [3][13]
o Improper Access Control vulnerability in Apache Tomcat(CVE-2026-65182) [4][14]
o Time-of-check Time-of-use (TOCTOU) Race Condition vulnerability in Apache Tomcat(CVE-2026-65183) [5][15]
o Uncontrolled Resource Consumption vulnerability in Apache Tomcat(CVE-2026-68763) [6][16]
o Incorrect Authorization vulnerability in Apache Tomcat(CVE-2026-66422) [7][17]
o Improper Input Validation vulnerability in Apache Tomcat(CVE-2026-65637) [8][18]
o Off-by-one Error vulnerability in Apache Tomcat(CVE-2026-65927) [9][19]
o Authentication Bypass by Capture-replay vulnerability in Apache Tomcat(CVE-2026-65905) [10][20]
