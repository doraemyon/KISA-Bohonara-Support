Title:
Check Point Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Check Point Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o Check Point has released security updates to address vulnerabilities in its products [1][2]
o Users running affected versions are advised to update to the latest version according to the mitigation measures
□ Description
o Missing Authorization vulnerability in Check Point Force Firewall, Management Server, Log Server, Multi-Domain Security Management, Multi-Domain Log Server, and Maestro Orchestrator(CVE-2026-123039) [1][3]
o Improper Handling of Exceptional Conditions vulnerability in Check Point Force Firewall, Spark Firewall, and Cloud Firewall(CVE-2026-109618) [2][4]
o Use After Free vulnerability in Check Point Force Firewall, Spark Firewall, and Cloud Firewall(CVE-2026-109619) [2][5]
