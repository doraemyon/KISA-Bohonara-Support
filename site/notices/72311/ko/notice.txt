제목:
Check Point 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Check Point 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Check Point社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1][2]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o Check Point Force Firewall, Management Server, Log Server, Multi-Domain Security Management, Multi-Domain Log Server, Maestro Orchestrator에서 발생하는 Missing Authorization 취약점(CVE-2026-123039) [1][3]
o Check Point Force Firewall, Spark Firewall, Cloud Firewall에서 발생하는 Improper Handling of Exceptional Conditions 취약점(CVE-2026-109618) [2][4]
o Check Point Force Firewall, Spark Firewall, Cloud Firewall에서 발생하는 Use After Free 취약점(CVE-2026-109619) [2][5]
