Title:
Cisco Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Cisco Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Cisco has released security updates to address vulnerabilities occurring in its products [1]
o The vulnerabilities are being actively exploited in actual attacks, and users operating affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Arbitrary File Write vulnerability occurring in Cisco Secure Email Gateway (CVE-2026-76519) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-76519 / Secure Email Gateway / Below 15.5.5-014 / 15.5.5-014 or later
CVE-2026-76519 / Secure Email Gateway / 16.0 / Migrate to 16.5.0-780
CVE-2026-76519 / Secure Email Gateway / Below 16.5.0-780 / 16.5.0-780 or later
※ Perform updates by checking the reference sites below [1]
