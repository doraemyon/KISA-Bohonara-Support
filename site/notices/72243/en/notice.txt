Title:
Redis Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Redis Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Redis has released security updates to resolve vulnerabilities occurring in its products [1]
o Users utilizing affected versions are advised to update to the latest version in accordance with the mitigation measures

□ Description
o Heap-based Buffer Overflow vulnerability occurring in Redis (CVE-2026-25243) [1][2]
