제목:
WordPress 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "WordPress 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o WordPress 재단은 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o WordPress에서 발생하는 PHP Remote File Inclusion 취약점(CVE-2026-87902) [1][2]
