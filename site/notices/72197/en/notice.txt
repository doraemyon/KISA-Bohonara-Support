Title:
WordPress Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "WordPress Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o The WordPress Foundation released security updates addressing vulnerabilities in its products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o PHP Remote File Inclusion vulnerability occurring in WordPress(CVE-2026-87902) [1][2]
