Title:
Atlassian Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Atlassian Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Atlassian announces security update that addresses vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Files or Directories Accessible to External Parties vulnerabilities occurring in Bitbucket Data Center, Confluence Data Center, Jira Service Management Data Center, Jira Software Data Center, Bamboo Data Center, Crowd Data Center, Crucible, and Fisheye (CVE-2026-21589) [1][2]
