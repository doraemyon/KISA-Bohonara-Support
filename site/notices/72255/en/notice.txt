Title:
Cisco Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Cisco Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Cisco releases security updates to address vulnerabilities in its products [1]
o Users running affected versions are advised to update to the latest version according to the workaround.

□ Description
o Unchecked Return Value to NULL Pointer Dereference Vulnerability in Cisco Secure Firewall Adaptive Security Appliance (ASA) and Secure Firewall Threat Defense (FTD)(CVE-2026-76418) [1][2]
