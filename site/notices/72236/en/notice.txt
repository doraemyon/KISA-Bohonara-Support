Title:
Node.js Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Node.js Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o OpenJS Foundation released security updates addressing vulnerabilities in their products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Improper Access Control vulnerability in Node.js(CVE-2026-105482) [1][2]
o Improper Certificate Validation vulnerability in Node.js(CVE-2026-105483) [1][3]
o Improper Certificate Validation vulnerability in Node.js(CVE-2026-106069) [1][4]
