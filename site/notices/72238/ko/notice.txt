제목:
Google 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Google 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Google社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o Google Brotli에서 발생하는 Out-of-bounds Write 취약점(CVE-2026-111497) [1][2]

□ 영향을 받는 제품 및 해결 방안
취약점 / 제품명 / 영향받는 버전 / 해결 버전
CVE-2026-111497 / Brotli / 1.0.3 이상 1.0.10 미만 / 1.0.10
CVE-2026-111497 / Brotli / 1.1.0 이상 1.1.1 미만 / 1.1.1
CVE-2026-111497 / Brotli / 1.2.0 이상 1.2.1 미만 / 1.2.1
※ 하단의 참고 사이트를 확인하여 업데이트 수행 [1]
※ 일부 제품은 Brotli 버전 변경 없이 취약점 수정 코드를 백포트하여 적용하였으므로, 제조사별 보안 업데이트 내역을 확인하여 조치 필요 [4]
※ Windows용 PHP에서 cURL을 통한 HTTP 응답 자동 압축 해제 기능이 활성화된 경우 해당 취약점의 영향을 받을 수 있으므로, PHP 8.2.35-1, 8.3.36-1, 8.4.27-1, 8.5.12-1 버전으로 업데이트 권고 [3]
