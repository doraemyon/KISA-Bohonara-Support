제목:
IBM 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "IBM 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o IBM社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[4]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o IBM MQ에서 발생하는 Improper Input Validation 취약점(CVE-2026-11724) [1][5]
o IBM API Connect에서 발생하는 Unrestricted Upload of File with Dangerous Type 취약점(CVE-2026-17399) [2][3][6]
o IBM API Connect에서 발생하는 Improper Authentication 취약점(CVE-2026-16720) [2][3][7]
o IBM Aspera Faspex에서 발생하는 Incorrect Authorization 취약점(CVE-2026-123218) [4][8]
