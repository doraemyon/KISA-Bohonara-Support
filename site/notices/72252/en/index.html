Title:
Palo Alto Networks Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Palo Alto Networks Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o Palo Alto Networks releases a security update to address vulnerabilities in its products. [1]
o Users running an affected version are advised to update to the latest version according to the workaround.
□ Description
o Improper Handling of Exceptional Conditions vulnerability in PHP included in Palo Alto Networks PAN-OS (CVE-2026-109618) [1][2]
o Use-After-Free Vulnerability in PHP Included in Palo Alto Networks PAN-OS (CVE-2026-109619) [1][3]
