제목:
Ascensio System 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Ascensio System 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Ascensio System社는 자사 ONLYOFFICE Docs(Document Server) 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o ONLYOFFICE Docs에서 발생하는 External Control of File Name or Path 취약점(CVE-2026-110385) [1][2]
o ONLYOFFICE Docs에서 발생하는 OS Command Injection 취약점(CVE-2026-113630) [1][3]
o ONLYOFFICE Docs에서 발생하는 인가 우회 및 파일 읽기 취약점(CVE-2026-113627) [1][4]
o ONLYOFFICE Docs에서 발생하는 Path Traversal 취약점(CVE-2026-97727) [1][5]
o ONLYOFFICE Docs에서 발생하는 Missing Authorization 취약점(CVE-2026-113631) [1][6]
o ONLYOFFICE Docs에서 발생하는 Server-Side Request Forgery 취약점(CVE-2026-110652) [1][7]

□ 영향을 받는 제품 및 해결 방안
