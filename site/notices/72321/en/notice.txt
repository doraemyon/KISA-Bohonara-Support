Title:
Ascensio System Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Ascensio System Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Ascensio System announced a security update that addresses vulnerabilities in its ONLYOFFICE Docs (Document Server) product. [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o External Control of File Name or Path vulnerability in ONLYOFFICE Docs (CVE-2026-110385) [1][2]
o OS Command Injection vulnerability occurring in ONLYOFFICE Docs (CVE-2026-113630) [1][3]
o Authorization bypass and file read vulnerabilities in ONLYOFFICE Docs (CVE-2026-113627) [1][4]
o Path Traversal Vulnerability in ONLYOFFICE Docs (CVE-2026-97727) [1][5]
o Missing Authorization vulnerability in ONLYOFFICE Docs (CVE-2026-113631) [1][6]
o Server-Side Request Forgery Vulnerability in ONLYOFFICE Docs (CVE-2026-110652) [1][7]

□ Affected Products and Solutions
