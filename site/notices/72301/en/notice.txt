Title:
Zoom Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Zoom Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Zoom announces security update that addresses vulnerabilities in its products [1][2]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Improper Input Validation Vulnerability in Zoom Workplace for Windows (CVE-2026-108186) [1][3]
o Origin Validation Error vulnerability in Zoom Workplace for Windows (CVE-2026-108187) [2][4]

□ Affected Products and Solutions

Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-108186 / Zoom Workplace for Windows / 7.1.0 or later and below 7.1.8 / 7.1.8 or later
CVE-2026-108187 / Zoom Workplace for Windows / Below 7.1.5 / 7.1.5 or later

※ Check the reference site below to perform updates [1][2]
