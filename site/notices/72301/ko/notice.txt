제목:
Zoom 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Zoom 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Zoom社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1][2]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o Zoom Workplace for Windows에서 발생하는 Improper Input Validation 취약점(CVE-2026-108186) [1][3]
o Zoom Workplace for Windows에서 발생하는 Origin Validation Error 취약점(CVE-2026-108187) [2][4]

□ 영향을 받는 제품 및 해결 방안

취약점 / 제품명 / 영향받는 버전 / 해결 버전
CVE-2026-108186 / Zoom Workplace for Windows / 7.1.0 이상 7.1.8 미만 / 7.1.8 이상
CVE-2026-108187 / Zoom Workplace for Windows / 7.1.5 미만 / 7.1.5 이상

※ 하단의 참고 사이트를 확인하여 업데이트 수행 [1][2]

□ 참고사이트

[2] https://www.zoom.com/en/trust/security-bulletin/zsb-26024

[4] https://nvd.nist.gov/vuln/detail/CVE-2026-108187
