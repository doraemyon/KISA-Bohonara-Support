Title:
Adobe Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Adobe Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Adobe has released security updates to address vulnerabilities in their products [1][2]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Incorrect Authorization vulnerability occurring in Adobe Commerce, Adobe Commerce B2B, and Magento Open Source(CVE-2026-71362) [1][2][3]
