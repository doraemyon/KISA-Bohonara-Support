Title:
Cisco Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Cisco Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Cisco announces security update that addresses vulnerabilities in its products [1][2]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Incorrect Use of Privileged APIs vulnerability in Cisco Identity Services Engine (ISE) and Cisco ISE Passive Identity Connector (ISE-PIC)(CVE-2026-76460) [1][3]
o SQL Injection vulnerability in Cisco AsyncOS Software for Cisco Secure Email Gateway (CVE-2026-76461) [2][4]
