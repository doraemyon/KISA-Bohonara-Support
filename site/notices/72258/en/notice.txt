Title:
Oracle Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Oracle Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Oracle announces security update that addresses vulnerabilities in its products [1][2]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Missing Authentication for Critical Function vulnerability occurring in Oracle Application Object Library (CVE-2026-101767) [1][3]
o Improper Privilege Management Vulnerability in Oracle Payments (CVE-2026-46817) [2][4]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-101767 / Oracle Application Object Library / 12.2.3-12.2.15 / Apply Oracle security patches
CVE-2026-46817 / Oracle Payments / 12.2.3-12.2.15 / Apply Oracle security patches
※ Check the reference site below to perform updates [1][2]
