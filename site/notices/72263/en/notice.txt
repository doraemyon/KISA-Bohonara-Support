Title:
Ivanti Product Security Update Recommendation

Summary:
We are disseminating today's KISA announcement "Ivanti Product Security Update Recommendation." We recommend that representatives at each affiliated company using the affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Ivanti has released a security update addressing vulnerabilities in its products [1]
o Users of affected versions are advised to update to the latest version following the workaround

□ Description
o Inclusion of Functionality from Untrusted Control Sphere vulnerability (CVE-2026-111357) in Ivanti Connect Secure [1][2]
o Generation of Predictable Numbers or Identifiers vulnerability (CVE-2026-118527) in Ivanti Connect Secure [1]

□ Affected Products and Workaround

Vulnerability / Product Name / Affected Version / Workaround Version
CVE-2026-111357 / Connect Secure / Less than 22.8R2.6 / 22.8R2.6 or higher
CVE-2026-111357 / Connect Secure / Less than 25.1.1.3 / 25.1.1.3 or higher
CVE-2026-118527 / Connect Secure / Below 22.8R2.6 / 22.8R2.6 or higher
CVE-2026-118527 / Connect Secure / Below 25.1.1.3 / 25.1.1.3 or higher

※ Please check the reference sites below to perform the update [1]
