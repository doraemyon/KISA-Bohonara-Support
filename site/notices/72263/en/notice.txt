Title:
Ivanti Product Security Update Advisory

Summary:
Today, we are forwarding the KISA notice "Ivanti Product Security Update Advisory". Personnel responsible for affected systems at each affiliated company are advised to apply the update and reply if there are any notable issues.

Body:
□ Overview
o Ivanti announces security updates that address vulnerabilities in its products [1]
o Users running an affected version are advised to update to the latest version according to the remediation guidance.

□ Description
o Inclusion of Functionality from Untrusted Control Sphere Vulnerability in Ivanti Connect Secure (CVE-2026-111357) [1] [2]
o Generation of Predictable Numbers or Identifiers Vulnerability in Ivanti Connect Secure (CVE-2026-118527) [1]

□ Affected Products and Remediation

Vulnerability / Product / Affected versions / Fixed versions
CVE-2026-111357 / Connect Secure / Earlier than 22.8R2.6 / 22.8R2.6 or later
CVE-2026-111357 / Connect Secure / Earlier than 25.1.1.3 / 25.1.1.3 or later
CVE-2026-118527 / Connect Secure / Earlier than 22.8R2.6 / 22.8R2.6 or later
CVE-2026-118527 / Connect Secure / Earlier than 25.1.1.3 / 25.1.1.3 or later
