제목:
Cisco 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Cisco 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Cisco社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o Cisco Secure Workload에서 발생하는 Injection 취약점(CVE-2026-20231) [1][2]
o Cisco Secure Workload에서 발생하는 Improper Access Control 취약점(CVE-2026-20315) [1][3]
o Cisco Secure Workload에서 발생하는 Improper Authentication 취약점(CVE-2026-20317) [1][4]
o Cisco Secure Workload에서 발생하는 Improper Input Validation 취약점(CVE-2026-20318) [1][5]
o Cisco Secure Workload에서 발생하는 Improper Restriction of Operations within the Bounds of a Memory Buffer 취약점(CVE-2026-20319) [1][6]
