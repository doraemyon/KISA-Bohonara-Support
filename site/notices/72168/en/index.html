Title:
Cisco Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Cisco Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o Cisco has released security updates to address vulnerabilities in their products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation measures
□ Description
o Injection vulnerability in Cisco Secure Workload(CVE-2026-20231) [1][2]
o Improper Access Control vulnerability in Cisco Secure Workload(CVE-2026-20315) [1][3]
o Improper Authentication vulnerability in Cisco Secure Workload(CVE-2026-20317) [1][4]
o Improper Input Validation vulnerability in Cisco Secure Workload(CVE-2026-20318) [1][5]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in Cisco Secure Workload(CVE-2026-20319) [1][6]
