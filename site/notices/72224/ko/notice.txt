제목:
F5 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "F5 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o F5社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[5]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o NGINX Plus, NGINX Open Source에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-15176) [1][6]
o NGINX Plus, NGINX Open Source에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-93479) [2][7]
o NGINX Plus, NGINX Open Source에서 발생하는 Use After Free 취약점(CVE-2026-97205) [3][8]
o NGINX Plus, NGINX Open Source에서 발생하는 Encoding Error 취약점(CVE-2026-95101) [4][9]
o NGINX Plus, NGINX Open Source에서 발생하는 Use of Uninitialized Resource 취약점(CVE-2026-97629) [5][10]
