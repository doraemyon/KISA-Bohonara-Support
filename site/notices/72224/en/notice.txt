Title:
F5 Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "F5 Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o F5 releases security updates to address vulnerabilities in its products [1]~[5]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Heap-based Buffer Overflow Vulnerability in NGINX Plus and NGINX Open Source (CVE-2026-15176) [1][6]
o Heap-based Buffer Overflow Vulnerability in NGINX Plus and NGINX Open Source (CVE-2026-93479) [2][7]
o Use-After-Free Vulnerability in NGINX Plus and NGINX Open Source (CVE-2026-97205) [3][8]
o Encoding Error Vulnerability in NGINX Plus and NGINX Open Source (CVE-2026-95101) [4][9]
o Use of Uninitialized Resource Vulnerability in NGINX Plus and NGINX Open Source (CVE-2026-97629) [5][10]
