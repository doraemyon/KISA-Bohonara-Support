Title:
Citrix Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Citrix Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Citrix announces security update that addresses vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability occurring in NetScaler ADC and NetScaler Gateway (CVE-2026-19489) [1][2]
o Authentication Bypass Using an Alternate Path or Channel vulnerability occurring in NetScaler ADC and NetScaler Gateway (CVE-2026-19490) [1][3]
