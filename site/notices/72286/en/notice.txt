Title:
Apache product security update advisories

Summary:
We are disseminating today's KISA announcement "Apache product security update advisories". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
Course Overview
o The Apache Foundation has released security updates addressing vulnerabilities in its products [1]
o Users with affected versions are advised to update to the latest version as a workaround

Description
o Cross-site Scripting (XSS) vulnerability in Apache Juneau (CVE-2026-96677) [1] [2]
o Insertion of Sensitive Information into Log File vulnerability in Apache Juneau (CVE-2026-73100) [1] [3]

□ Affected Products and Solutions

Vulnerability / product name / Affected version / Resolved version
CVE-2026-96677 / Apache Juneau / Less than 9.2.1 / 9.2.1 or later
CVE-2026-73100 / Apache Juneau / Less than 9.2.1 / 9.2.1 or later
