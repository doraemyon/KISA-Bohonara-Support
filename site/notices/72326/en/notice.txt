Title:
Splunk Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Splunk Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Splunk releases security updates to address vulnerabilities in its products [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Improper Authentication Vulnerability in Splunk Enterprise (CVE-2026-76536) [1][2]
o Improper Authentication Vulnerability in Splunk Enterprise (CVE-2026-76535) [1][3]

o Missing Authorization Vulnerability in Splunk Enterprise (CVE-2026-76540) [1][5]
o Command Injection Vulnerability in Splunk Enterprise (CVE-2026-76544) [1][6]

o Injection vulnerabilities in Splunk Enterprise (CVE-2026-131178) [1][8]
o Injection vulnerabilities in Splunk Enterprise (CVE-2026-131179) [1][9]
o Improper Encoding or Escaping of Output vulnerability in Splunk Enterprise (CVE-2026-131182) [1][10]
o Use of Hard-coded Credentials Vulnerability in Splunk Enterprise (CVE-2026-131190) [1][11]
o Authentication Bypass by Primary Weakness Vulnerability in Splunk Enterprise (CVE-2026-131192) [1][12]
