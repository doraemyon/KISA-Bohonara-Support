Title:
Synology Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Synology Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Synology releases security updates to address vulnerabilities in its products [1]
o Users running affected versions are advised to update to the latest version according to the workaround.

□ Description
o Insufficient Entropy Vulnerability in Synology DiskStation Manager (DSM)(CVE-2026-13639) [1][2]
o Improper Encoding or Escaping of Output vulnerability in Synology DiskStation Manager (DSM)(CVE-2026-13684) [1][3]
o Incorrect Permission Assignment for Critical Resource vulnerability in Synology DiskStation Manager (DSM)(CVE-2026-13673) [1][4]
o External Control of File Name or Path vulnerability in Synology DiskStation Manager (DSM)(CVE-2026-6205) [1][5]
