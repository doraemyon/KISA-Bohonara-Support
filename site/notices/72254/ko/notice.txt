제목:
Synology 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Synology 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Synology社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o Synology DiskStation Manager(DSM)에서 발생하는 Insufficient Entropy 취약점(CVE-2026-13639) [1][2]
o Synology DiskStation Manager(DSM)에서 발생하는 Improper Encoding or Escaping of Output 취약점(CVE-2026-13684) [1][3]
o Synology DiskStation Manager(DSM)에서 발생하는 Incorrect Permission Assignment for Critical Resource 취약점(CVE-2026-13673) [1][4]
o Synology DiskStation Manager(DSM)에서 발생하는 External Control of File Name or Path 취약점(CVE-2026-6205) [1][5]
