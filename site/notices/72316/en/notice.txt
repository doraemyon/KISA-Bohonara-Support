Title:
F5 Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "F5 Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o F5 releases a security update to address vulnerabilities in its products. [1]~[12]
o Users running affected versions are advised to update to the latest version according to the workaround.

□ Description
o Stack-based Buffer Overflow Vulnerability in BIG-IP Access Policy Manager (APM)(CVE-2026-123637) [1][13]
o Stack-based Buffer Overflow Vulnerability in BIG-IP Policy Enforcement Manager (PEM), BIG-IP CNF, and BIG-IP Next for Kubernetes (CVE-2026-121805) [2][14]
o Stack-based Buffer Overflow Vulnerability in BIG-IP, BIG-IP CNF, and BIG-IP Next for Kubernetes (CVE-2026-120292) [3][15]
o Stack-based Buffer Overflow Vulnerability in BIG-IP, BIG-IP CNF, and BIG-IP Next for Kubernetes (CVE-2026-120285) [4][16]
o Stack-based Buffer Overflow Vulnerability in BIG-IP, BIG-IP CNF, and BIG-IP Next for Kubernetes (CVE-2026-116953) [5][17]
o Stack-based Buffer Overflow Vulnerability in BIG-IP DNS, BIG-IP CNF, and BIG-IP Next for Kubernetes (CVE-2026-120722) [6][18]
o Vulnerabilities in BIG-IP (CVE-2026-120718) [7][19]
o CRLF Injection Vulnerability in BIG-IP and BIG-IQ Centralized Management (CVE-2026-125274) [8][20]
o Stack-based Buffer Overflow Vulnerability in BIG-IP Access Policy Manager (APM)(CVE-2026-125272) [9][21]
o Integer Underflow (Wrap or Wraparound) Vulnerability in BIG-IP Access Policy Manager (APM)(CVE-2026-126822) [10][22]
o Integer Underflow (Wrap or Wraparound) Vulnerability in BIG-IP Access Policy Manager (APM)(CVE-2026-126336) [11][23]
o Integer Underflow (Wrap or Wraparound) Vulnerability in BIG-IP Access Policy Manager (APM) and BIG-IP SSL Orchestrator (CVE-2026-121812) [12][24]
