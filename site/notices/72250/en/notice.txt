Title:
Samba Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Samba Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Samba releases a security update to address vulnerabilities in its products [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Improper Handling of Case Sensitivity Vulnerability in Samba (CVE-2026-109411) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-109411 / Samba / 4.25.0 or later and below 4.25.1 / 4.25.1 or later
※ Perform updates by referring to the sites listed below. [1]
