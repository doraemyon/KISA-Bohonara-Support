Title:
Citrix Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Citrix Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Citrix releases security updates to address vulnerabilities in its products [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Out-of-bounds Read Vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-8451) [1][2]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-8452) [1][3]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-8655) [1][4]
o External Control of File Name or Path vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-10816) [1][5]
o Missing Release of Memory after Effective Lifetime vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-13474) [1][6]
