Title:
PHP Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "PHP Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o The PHP Group announces a security update that addresses vulnerabilities in its products. [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Improper Handling of Exceptional Conditions vulnerability in PHP (CVE-2026-109618) [1][2]
o Use-After-Free Vulnerability in PHP (CVE-2026-109619) [1][3]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-109618 / PHP 8.2 / Below 8.2.35 / 8.2.35 or later
CVE-2026-109618 / PHP 8.3 / Below 8.3.36 / 8.3.36 or later
CVE-2026-109618 / PHP 8.4 / Below 8.4.27 / 8.4.27 or later
CVE-2026-109618 / PHP 8.5 / Below 8.5.12 / 8.5.12 or later
CVE-2026-109619 / PHP 8.2 / Below 8.2.35 / 8.2.35 or later
CVE-2026-109619 / PHP 8.3 / Below 8.3.36 / 8.3.36 or later
CVE-2026-109619 / PHP 8.4 / Below 8.4.27 / 8.4.27 or later
CVE-2026-109619 / PHP 8.5 / Below 8.5.12 / 8.5.12 or later
※ PHP 8.1 For versions earlier than this, official security support has ended, and it is recommended to upgrade to a supported version. [1]
※ PHP 7.4, 8.0, 8.1 Since versions may vary in terms of the resolved versions and temporary mitigations for each vendor, it is recommended to check the security recommendations of the respective vendor and take appropriate action.
※ Perform updates by referring to the sites listed below. [1]
