Title:
Security Update Advisory for Cyber Imagination Products

Summary:
We are disseminating today's KISA announcement "Security Update Advisory for Cyber Imagination Products". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

o Cyber Imagination has released a security update addressing a vulnerability in its product [1]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures

Product Name / Affected Version / Fixed Version
D-Bridge / 1.x / 2.5 or later
