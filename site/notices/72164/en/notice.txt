Title:
PostgreSQL Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "PostgreSQL Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o PostgreSQL Foundation announces security update that addresses vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Inclusion of Functionality from Untrusted Control Sphere vulnerability in PostgreSQL (CVE-2026-6464) [1][2]
o Missing Authorization vulnerability in PostgreSQL (CVE-2026-6471) [1][3]
