제목:
Fortinet 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Fortinet 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Fortinet社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[14]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o FortiManager에서 발생하는 Improper Authorization 취약점(CVE-2026-126261) [1][15]
o FortiAnalyzer, FortiManager에서 발생하는 SQL Injection 취약점(CVE-2026-126262) [2][16]
o FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud에서 발생하는 Authentication Bypass by Spoofing 취약점(CVE-2026-126184) [3][17]
o FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud에서 발생하는 Improper Certificate Validation 취약점(CVE-2026-126232) [4][18]
o FortiOS에서 발생하는 Missing Authentication for Critical Function 취약점(CVE-2026-126259) [5][19]
o FortiOS에서 발생하는 Authentication Bypass by Primary Weakness 취약점(CVE-2026-126253) [6][20]
o FortiOS에서 발생하는 Out-of-bounds Read 취약점(CVE-2026-126256) [7][21]
o FortiOS에서 발생하는 Stack-based Buffer Overflow 취약점(CVE-2026-126258) [8][22]
o FortiOS에서 발생하는 Improper Certificate Validation 취약점(CVE-2026-121528) [9][23]
o FortiAnalyzer, FortiAnalyzer Cloud, FortiAnalyzer-BigData, FortiManager, FortiManager Cloud에서 발생하는 Improper Encoding or Escaping of Output 취약점(CVE-2026-126170) [10][24]
o FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud에서 발생하는 XML Injection 취약점(CVE-2026-126176) [11][25]
o FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud에서 발생하는 XML Injection 취약점(CVE-2026-126177) [11][26]
o FortiOS, FortiPAM에서 발생하는 Path Traversal 취약점(CVE-2026-126255) [12][27]
o FortiManager에서 발생하는 Use of Hard-coded Credentials 취약점(CVE-2026-126181) [13][28]
o FortiOS에서 발생하는 Numeric Truncation Error 취약점(CVE-2026-126254) [14][29]
