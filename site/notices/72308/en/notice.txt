Title:
Fortinet Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Fortinet Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Fortinet announces security updates that address vulnerabilities in its products [1]~[14]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Improper Authorization vulnerability in FortiManager (CVE-2026-126261) [1][15]
o SQL Injection vulnerability occurring in FortiAnalyzer and FortiManager (CVE-2026-126262) [2][16]
o Authentication Bypass by Spoofing vulnerability occurring in FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, and FortiManager Cloud (CVE-2026-126184) [3][17]
o Improper Certificate Validation vulnerability occurring in FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, and FortiManager Cloud (CVE-2026-126232) [4][18]
o Missing Authentication for Critical Function vulnerability occurring in FortiOS (CVE-2026-126259) [5][19]
o Authentication Bypass by Primary Weakness vulnerability occurring in FortiOS (CVE-2026-126253) [6][20]
o Out-of-bounds Read vulnerability in FortiOS (CVE-2026-126256) [7][21]
o Stack-based Buffer Overflow vulnerability occurring in FortiOS (CVE-2026-126258) [8][22]
o Improper Certificate Validation vulnerability occurring in FortiOS (CVE-2026-121528) [9][23]
o Improper Encoding or Escaping of Output vulnerabilities occurring in FortiAnalyzer, FortiAnalyzer Cloud, FortiAnalyzer-BigData, FortiManager, and FortiManager Cloud (CVE-2026-126170) [10][24]
o XML Injection vulnerability occurring in FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, and FortiManager Cloud (CVE-2026-126176) [11][25]
o XML Injection vulnerability occurring in FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, and FortiManager Cloud (CVE-2026-126177) [11][26]
o Path traversal vulnerability occurring in FortiOS and FortiPAM (CVE-2026-126255) [12][27]
o Use of Hard-coded Credentials vulnerability in FortiManager (CVE-2026-126181) [13][28]
o Numeric Truncation Error vulnerability occurring in FortiOS (CVE-2026-126254) [14][29]
