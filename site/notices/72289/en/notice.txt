Title:
Infinite Healthcare Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Infinite Healthcare Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Infinite Healthcare announces a security update that addresses vulnerabilities in its products [1]
o Users with affected versions are advised to update to the latest version as a workaround

□ Description
o Cross-site Scripting vulnerability in infinite ULite (CVE-2026-19876) [1] [2]
o Password Brute Force vulnerability in infinite ULite (CVE-2026-19877) [1] [3]

□ Affected Products and Solutions
Vulnerability / product name / Affected version / Resolved version

CVE-2026-19877 / INFINITT ULite / 5.0.2.1_BN48_20260528 or less / 5.0.2.1 BN50 or higher
