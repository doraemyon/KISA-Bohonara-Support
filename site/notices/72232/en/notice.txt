Title:
GitLab Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "GitLab Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o GitLab has released security updates to address vulnerabilities in its products [1][2]
o Users running affected versions are advised to update to the latest version according to the mitigation instructions

□ Description
o Integer Overflow or Wraparound vulnerability in GitLab CE/EE(CVE-2026-110264) [1][3]
o Integer Overflow or Wraparound vulnerability in GitLab CE/EE(CVE-2026-93577) [2][4]
o Double Free vulnerability in GitLab CE/EE(CVE-2026-89078) [2][5]
o LDAP Injection vulnerability in GitLab CE/EE(CVE-2026-15723) [1][6]
o HTTP Request/Response Smuggling vulnerability in GitLab CE/EE(CVE-2026-112212) [1][7]
