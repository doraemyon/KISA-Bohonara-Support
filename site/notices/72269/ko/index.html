제목:
지란지교소프트 제품 보안 조치 권고
요약:
금일 KISA 공지 "지란지교소프트 제품 보안 조치 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.
본문:
□ 개요
o 지란지교소프트社는 자사 제품에서 발견된 보안 취약점에 대한 조치 방법 발표 [1]
o 해당 제품을 사용 중인 사용자는 제조사 권고에 따라 샘플파일 삭제 등 보안 조치 권고
□ 설명
o CrossUploader에서 발생하는 부적절한 파일 업로드 취약점 [1]
□ 영향을 받는 제품 및 조치 방안
제조사 / 제품명 / 영향받는 버전 / 조치 방안
지란지교소프트 / CrossUploader / 1.0.00 이상 3.0.09 이하 / 샘플파일(UploadProcess.jsp) 삭제 및 보안 설정
□ 보안 조치 방법
1. 운영 환경에서 아래 샘플 폴더가 존재하는 경우 삭제 권고 [1]
- /NamoCrossUploaderH5Samples
- /NamoCrossUploaderJaSamples
2. 기본 설치 경로 외 다른 경로에도 UploadProcess.jsp 파일이 존재하는지 확인 후 불필요한 파일 삭제 권고
3. 웹 접근 로그에서 해당 파일의 호출 이력을 확인하고, 업로드 경로에 JSP 등 비정상적인 스크립트 파일이 생성되었는지 점검 권고
4. 해당 샘플파일을 실제 서비스에 사용하는 경우 아래 보안 조치 적용 권고
- 업무상 필요한 파일 확장자만 업로드 허용
- 업로드 요청에 대한 사용자 인증 및 접근 권한 검증
- 서버 측 파일 확장자, 내용 및 파일명 검증
- 웹에서 직접 접근할 수 없는 경로에 업로드 파일 저장
- 업로드 폴더에서 JSP 등 서버 측 스크립트 실행 차단
※ 샘플 폴더는 기능 테스트용으로, 실제 서비스에 사용하지 않는 경우 삭제하더라도 제품의 정상 동작에는 영향 없음
※ 해당 샘플파일을 실제 서비스에서 사용 중인 경우 삭제 전 서비스 영향 여부를 확인하고 조치 필요
※ 별도 보안 업데이트 버전은 안내되지 않았으며, 제조사에서 권고한 샘플파일 제거 및 보안 조치 수행 필요
