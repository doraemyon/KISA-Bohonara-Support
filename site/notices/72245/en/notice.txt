Title:
Splunk Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Splunk Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Splunk releases a security update to address vulnerabilities in its products [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o SSRF Vulnerability in Cisco Talos Intelligence for Enterprise Security Cloud (CVE-2026-76389) [1][2]
o Incorrect Authorization Vulnerability in Splunk AI Toolkit (CVE-2026-76391) [1][3]
o Missing Authorization Vulnerability in Splunk AI Toolkit (CVE-2026-76394) [1][4]
o Deserialization of Untrusted Data Vulnerability in Splunk AI Toolkit (CVE-2026-76395) [1][5]
o Improper Privilege Management Vulnerability in Splunk AI Toolkit (CVE-2026-76396) [1][6]
o Authorization Bypass Through User-Controlled Key Vulnerability in Splunk AI Toolkit (CVE-2026-76397) [1][7]
o Incorrect Permission Assignment for Critical Resource vulnerability in Splunk AI Toolkit (CVE-2026-76399) [1][8]
o SSRF vulnerability in Splunk Connect for Kafka (CVE-2026-76402) [1][9]
o Improper Certificate Validation Vulnerability in Splunk Connect for Kafka (CVE-2026-76403) [1][10]
o Deserialization of Untrusted Data vulnerability in the Splunk MCP Server app (CVE-2026-76404) [1][11]
