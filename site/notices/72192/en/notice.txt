Title:
Check Point Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Check Point Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Check Point announces security update that addresses vulnerabilities in its products [1]~[6]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Stack-based Buffer Overflow vulnerability occurring in Security Management Server, Multi-Domain Security Management Server, Log Server, and Multi-Domain Log Server (CVE-2026-91843) [1][7]
o Improper Authentication vulnerability occurring in Security Management Server and Multi-Domain Security Management Server (CVE-2026-16232) [2][8]
o Improper Authentication vulnerability occurring in Security Management Server and Multi-Domain Security Management Server (CVE-2026-62144) [3][9]
o Authentication Bypass Using Alternate Path or Channel vulnerability occurring in Security Management Server, Multi-Domain Security Management Server (CVE-2026-18574) [4][10]
o Heap-based Buffer Overflow vulnerability occurring in Security Gateway, Security Management Server, and Spark Firewall (CVE-2026-85103) [5][11]
o Improper Certificate Validation vulnerability occurring in Security Gateway and Spark Firewall (CVE-2026-85102) [6][12]
