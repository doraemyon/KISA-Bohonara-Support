Title:
SonicWall Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "SonicWall Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o SonicWall has released security updates to address vulnerabilities in its products [1]
o Users utilizing affected versions are recommended to update to the latest version according to the mitigation measures

□ Description
o Server-Side Request Forgery (SSRF) vulnerability occurring in SonicWall SMA1000(CVE-2026-102255) [1][2]
o OS Command Injection vulnerability occurring in SonicWall SMA1000(CVE-2026-102256) [1][3]
o Path Traversal vulnerability occurring in SonicWall SMA1000(CVE-2026-102257) [1][4]
