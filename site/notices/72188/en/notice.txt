Title:
Gitea Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Gitea Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Gitea project announces security update that addresses vulnerabilities occurring in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.
o Recently, attacks and damage have occurred due to this vulnerability, so users need to be careful.

□ Description
o Code injection vulnerability occurring in Gitea (CVE-2026-60004) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-60004 / Gitea / 1.17 or later and below 1.27.1 / 1.27.1 or later
