Title:
WordPress Plugin Security Update Advisory

Summary:
We are disseminating today's KISA announcement "WordPress Plugin Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Announcing security updates that addressed a vulnerability in the Contact Form 7 plugin in WordPress [1]
o Users with affected versions are advised to update to the latest version as a workaround

□ Description
o Unrestricted Upload of File with Dangerous Type vulnerability in Contact Form 7 (CVE-2026-114432) [1] [2]

□ Affected Products and Solutions

Vulnerability / product name / Affected version / Resolved version
CVE-2026-114432 / Contact Form 7 / 6.2.0 to less than 6.2.4 / 6.2.4 or more

※ Check the reference site below to perform the update [1]
