제목:
PHP 신규 취약점(CVE-2026-115560) 임시 조치 권고

요약:
금일 KISA 공지 "PHP 신규 취약점(CVE-2026-115560) 임시 조치 권고" 전파드리오니, 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o PHP 개발팀은 자사 제품에서 발생하는 원격 코드 실행 취약점에 대한 임시 조치 방안 발표 [1]
o 해당 취약점은 보안 업데이트가 배포되지 않은 상태로, 영향을 받는 설정을 사용 중인 사용자는 해결 방안에 따라 임시 조치 적용 권고
※ 영향받는 버전 및 보안 업데이트 등 추가 정보 공개 시 본 공지 내용 업데이트 예정

□ 설명
o PHP 세션 처리 과정에서 발생하는 원격 코드 실행 취약점(CVE-2026-115560) [1][2]

□ 영향을 받는 제품 및 해결 방안
취약점 / 제품명 / 영향받는 버전 / 해결 버전
CVE-2026-115560 / PHP / 제조사 미공개 / 미배포(차기 정기 업데이트 예정)
※ 다음 조건을 모두 충족하는 경우에만 영향을 받음 [1]
※ 제조사에서 영향받는 버전 및 해결버전 공개 시 업데이트 예정

o 설정 파일에서 session.serialize_handler를 php_binary 또는 php_serialize로 지정
o session_start() 호출 전 ini_set()으로 해당 값을 php로 변경
o session.upload_progress.enabled 활성화(기본값)
※ 보안 업데이트 배포 전까지 php.ini, PHP-FPM pool 설정 등에서 session.upload_progress.enabled=0 설정 후 모든 PHP 워커 재시작 [1]
※ 10.21. 배포된 보안 업데이트(8.5.12, 8.4.27, 8.3.36, 8.2.35)로는 해결되지 않으며, PHP2Shell(CVE-2026-109619) 임시 조치로 위 설정을 이미 적용한 경우 추가 조치 불필요
