Title:
Zyxel Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Zyxel Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o Zyxel announces security update that addresses vulnerabilities in its products [1][2]
o Users using the affected version are advised to update to the latest version as per the resolution.
□ Description
o Out-of-bounds write vulnerability occurring in GS1900 series switches (CVE-2026-107441) [1][3]
o Classic Buffer Overflow vulnerability occurring in AP, FWA7, and Security Router (CVE-2026-76955) [2][4]
