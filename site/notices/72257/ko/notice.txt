제목:
VMware 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "VMware 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Broadcom社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o VMware Telco Cloud Platform, VMware Cloud Foundation, VMware ESX, VMware vSphere Foundation에서 발생하는 Insufficient Logging 취약점(CVE-2026-41709) [1][2]

□ 영향을 받는 제품 및 해결 방안
취약점 / 제품명 / 영향받는 버전 / 해결 버전

CVE-2026-41709 / VMware Telco Cloud Platform / 5.1.x / 8.0 U3j 이상
CVE-2026-41709 / VMware Cloud Foundation / 5.x / 5.2.4 이상
CVE-2026-41709 / VMware ESX / 8.0 / ESXi80U3j-25429389 이상
CVE-2026-41709 / VMware Cloud Foundation / 9.0.x.x / ESXi-9.0.2.0100-25595025 이상
CVE-2026-41709 / VMware vSphere Foundation / 9.0.x.x / ESXi-9.0.2.0100-25595025 이상
CVE-2026-41709 / VMware Cloud Foundation / 9.1.x.x / ESXi-9.1.0.0-25370933 이상
CVE-2026-41709 / VMware vSphere Foundation / 9.1.x.x / ESXi-9.1.0.0-25370933 이상
※ 하단의 참고 사이트를 확인하여 업데이트 수행 [1]
