Title:
VMware Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "VMware Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Broadcom announces security update that addresses vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Insufficient Logging vulnerability in VMware Telco Cloud Platform, VMware Cloud Foundation, VMware ESX, and VMware vSphere Foundation (CVE-2026-41709) [1][2]
