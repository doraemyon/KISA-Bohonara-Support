Title:
WordPress Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "WordPress Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o WordPress Foundation Announces Security Update Addressing Vulnerabilities in Its Products [1][2]
o Users using the affected version are advised to update to the latest version as per the resolution.
□ Description
o Time-of-check Time-of-use (TOCTOU) Race Condition vulnerability in WordPress (CVE-2026-119977) [1]~[3]
