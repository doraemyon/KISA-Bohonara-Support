Title:
Fortinet Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Fortinet Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Fortinet has released security updates to address vulnerabilities in its products [1]
o Users operating affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Path Traversal vulnerability in FortiSIEM (CVE-2026-106173) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Versions / Fixed Version
CVE-2026-106173 / FortiSIEM / 7.5.0 / 7.5.1 or later
※ Perform the update by checking the reference site below [1]

□ Reference sites
[1] https://fortiguard.fortinet.com/psirt/FG-IR-26-180
[2] https://nvd.nist.gov/vuln/detail/CVE-2026-106173

□ Questions and inquiries
