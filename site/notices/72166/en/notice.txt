Title:
MLflow Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "MLflow Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o The MLflow project announces security updates that address vulnerabilities occurring in its products. [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Server-Side Request Forgery (SSRF) vulnerability occurring in MLflow (CVE-2026-64849) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-64849 / MLflow / Below 3.15.0 / 3.15.0 or later
※ Check the reference site below to perform updates [1]
