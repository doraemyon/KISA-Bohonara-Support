Title:
Citrix Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Citrix Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o Citrix releases security updates to address vulnerabilities in its products [1]
o Users running affected versions are advised to update to the latest version according to the workaround.
□ Description
o Improper Input Validation Vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-88771) [1][2]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-88772) [1][3]
o HTTP Request/Response Smuggling Vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-88773) [1][4]
o Vulnerabilities due to insufficient security settings in NetScaler ADC and NetScaler Gateway (CVE-2026-88774) [1][5]
o Classic Buffer Overflow Vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-88775) [1][6]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-88776) [1][7]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-88777) [1][8]
o Predictable Exact Value from Previous Values vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-88778) [1][9]
