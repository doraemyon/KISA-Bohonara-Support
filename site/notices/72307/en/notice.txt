Title:
Git Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Git Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Announcement of security update that resolves vulnerabilities occurring in Git packages [1][2]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Vulnerabilities occurring in Git (CVE-2026-111760) [1][2]
o Heap-based Buffer Overflow vulnerability occurring in Git (CVE-2026-105437) [2][3]
