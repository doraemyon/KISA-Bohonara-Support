Title:
Cisco Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Cisco Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Cisco has released security updates to address vulnerabilities in its products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Hex encoding vulnerability in Cisco Catalyst SD-WAN Manager (CVE-2026-76504) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-76504 / Catalyst SD-WAN Manager / Less than 20.9 / Migrate to a fixed version
CVE-2026-76504 / Catalyst SD-WAN Manager / 20.9 and above less than 20.9.10.1 / 20.9.10.1 and above
CVE-2026-76504 / Catalyst SD-WAN Manager / 20.12 and above less than 20.12.8.2 / 20.12.8.2 and above
