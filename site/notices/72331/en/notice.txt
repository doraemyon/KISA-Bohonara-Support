Title:
Synology Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Synology Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Synology has released security updates addressing vulnerabilities occurring in its products [1]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Argument Injection vulnerability occurring in Synology DiskStation Manager (DSM) (CVE-2026-120382) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Resolution Version
