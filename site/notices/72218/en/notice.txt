Title:
Palo Alto Networks Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Palo Alto Networks Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Palo Alto Networks has released security updates to address vulnerabilities affecting their products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Code Injection vulnerability occurring in PAN-OS (CVE-2026-0322) [1][2]
