Title:
PostgreSQL Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "PostgreSQL Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o PostgreSQL Foundation announces security update that addresses vulnerabilities in its products [1]~[6]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Integer Overflow or Wraparound vulnerability occurring in PostgreSQL (CVE-2026-6473) [1][7]
o UNIX Symbolic Link (Symlink) Following vulnerability occurring in PostgreSQL (CVE-2026-6475) [2][8]
o Use of Inherently Dangerous Function vulnerability in PostgreSQL (CVE-2026-6477) [3][9]
o Uncontrolled Recursion Vulnerability in PostgreSQL (CVE-2026-6479) [4][10]
o Stack-based Buffer Overflow vulnerability occurring in PostgreSQL (CVE-2026-6637) [5][11]
o SQL Injection vulnerability occurring in PostgreSQL (CVE-2026-6476) [6][12]
