Title:
NGINX Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "NGINX Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o F5 has released security updates addressing vulnerabilities in its NGINX products [1][2][3][4][5]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Integer Underflow (Wrap or Wraparound) vulnerability occurring in NGINX Plus and NGINX Open Source(CVE-2026-123007) [1][6]
o Use After Free vulnerability occurring in NGINX Plus and NGINX Open Source(CVE-2026-123634) [2][7]
o Use After Free vulnerability occurring in NGINX Plus and NGINX Open Source(CVE-2026-123633) [3][8]
o Use After Free vulnerability occurring in NGINX Plus and NGINX Open Source(CVE-2026-121810) [4][9]
o Use After Free vulnerability occurring in NGINX Plus and NGINX Open Source(CVE-2026-113425) [5][10]
