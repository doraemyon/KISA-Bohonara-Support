Title:
GitLab Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "GitLab Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o GitLab announces security update that addresses vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Path Traversal Vulnerability Occurring in GitLab CE/EE (CVE-2026-85706) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version

CVE-2026-85706 / GitLab CE / 19.2 or later and below 19.2.6 / 19.2.6 or later
CVE-2026-85706 / GitLab CE / 19.3 or later and below 19.3.2 / 19.3.2 or later
CVE-2026-85706 / GitLab EE / 18.7 or later and below 19.1.8 / 19.1.8 or later
CVE-2026-85706 / GitLab EE / 19.2 or later and below 19.2.6 / 19.2.6 or later
CVE-2026-85706 / GitLab EE / 19.3 or later and below 19.3.2 / 19.3.2 or later
