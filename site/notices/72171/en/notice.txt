Title:
H2 Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "H2 Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Security update announcement addressing vulnerabilities occurring in H2 Database [1][2]
o Users utilizing affected versions are recommended to update to the latest version according to the mitigation measures

□ Description
o Deserialization of Untrusted Data vulnerability occurring in H2 Database (CVE-2021-42392) [1][3]
o Argument Injection vulnerability occurring in H2 Database (CVE-2022-23221) [2][4]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2021-42392 / H2 Database / 1.1.100 or higher 2.0.204 or lower / 2.0.206 or higher
CVE-2022-23221 / H2 Database / Less than 2.1.210 / 2.1.210 or higher
※ Check the reference sites below and perform the update [1][2]
