Title:
WordPress Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "WordPress Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Announced security update to address vulnerabilities in WordPress weDevs Project Manager plugin [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Unrestricted Upload of File with Dangerous Type vulnerability occurring in weDevs Project Manager (CVE-2026-116512) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-116512 / weDevs Project Manager / Below 4.1.2 / 4.1.2 or later
※ Check the reference site below to perform updates [1]
