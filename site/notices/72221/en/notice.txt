Title:
Vercel Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Vercel Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Vercel announces a security update to address vulnerabilities in its products. [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Use-After-Free Vulnerability in Next.js (CVE-2026-96889) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-96889 / Next.js / Below 15.5.28 / 15.5.28 or later
CVE-2026-96889 / Next.js / Below 16.4.1 / 16.4.1 or later
※ Perform updates by referring to the sites listed below. [1]

□ Reference sites
[1] https://nextjs.org/blog/nextjs-security-update-october-14-2026
[2] https://nvd.nist.gov/vuln/detail/CVE-2026-96889
