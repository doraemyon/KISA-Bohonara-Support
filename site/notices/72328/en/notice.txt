Title:
VMware Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "VMware Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Broadcom announces security update that addresses vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Vulnerabilities occurring in VMware Telco Cloud Platform, VMware Telco Cloud Infrastructure, VMware Cloud Foundation, VMware vCenter, and VMware vSphere Foundation (CVE-2026-123903) [1]
o Vulnerabilities in VMware Telco Cloud Platform, VMware Cloud Foundation, VMware ESX, and VMware vSphere Foundation (CVE-2026-123910) [1]
o Vulnerabilities in VMware Telco Cloud Platform, VMware Cloud Foundation, VMware ESX, and VMware vSphere Foundation (CVE-2026-123911) [1]
o Vulnerabilities in VMware Telco Cloud Platform, VMware Cloud Foundation, VMware ESX, VMware vSphere Foundation, VMware Workstation, and VMware Fusion (CVE-2026-123912) [1]
o Vulnerabilities in VMware Telco Cloud Platform, VMware Cloud Foundation, VMware ESX, and VMware vSphere Foundation (CVE-2026-123913) [1]
o Vulnerabilities occurring in VMware Telco Cloud Platform, VMware Telco Cloud Infrastructure, VMware Cloud Foundation, VMware vCenter, and VMware vSphere Foundation (CVE-2026-123904) [1]
o Vulnerabilities occurring in VMware Telco Cloud Platform, VMware Telco Cloud Infrastructure, VMware Cloud Foundation, VMware vCenter, and VMware vSphere Foundation (CVE-2026-123905) [1]
o Vulnerabilities occurring in VMware Telco Cloud Platform, VMware Telco Cloud Infrastructure, VMware Cloud Foundation, VMware vCenter, and VMware vSphere Foundation (CVE-2026-123906) [1]
