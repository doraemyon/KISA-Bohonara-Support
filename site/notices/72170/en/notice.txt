Title:
Gitea Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Gitea Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Security update released to address vulnerabilities occurring in Gitea [1]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Code Injection vulnerability occurring in Gitea (CVE-2026-60004) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Resolved Version
CVE-2026-60004 / Gitea / 1.17 or later and 1.27.1 before / 1.27.1 or later
※ Check the reference sites below to perform the update [1]
