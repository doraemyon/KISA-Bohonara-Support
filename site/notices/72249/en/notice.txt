Title:
Juniper Networks Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Juniper Networks Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Juniper Networks announces a security update to address vulnerabilities in its products. [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Link Following Vulnerability in Juniper Session Smart Router and Session Smart Conductor (CVE-2026-103401) [1][2]
o Insufficient Verification of Data Authenticity vulnerability in Juniper Session Smart Router and Session Smart Conductor (CVE-2026-103402) [1][3]
o OS Command Injection Vulnerability in Juniper Session Smart Router and Session Smart Conductor (CVE-2026-103403) [1][4]
o OS Command Injection Vulnerability in Juniper Session Smart Conductor (CVE-2026-103406) [1][5]
o Path Traversal Vulnerability in Juniper Session Smart Router and Session Smart Conductor (CVE-2026-103407) [1][6]
o Stack-based Buffer Overflow Vulnerability in Juniper Session Smart Router (CVE-2026-103408) [1][7]
o Missing Authentication for Critical Function vulnerability in Juniper Session Smart Router (CVE-2026-103409) [1][8]
o Integer Overflow or Wraparound Vulnerability in Juniper Session Smart Router (CVE-2026-103410) [1][9]
o Integer Underflow Vulnerability in Juniper Session Smart Router (CVE-2026-103411) [1][10]
o OS Command Injection Vulnerability in Juniper Session Smart Router and Session Smart Conductor (CVE-2026-106079) [1][11]
