제목:
엠투소프트 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "엠투소프트 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o 엠투소프트社는 자사 제품의 취약점을 해결한 보안 업데이트를 발표함 [1][2]
o 낮은 버전을 사용 중인 사용자는 제조사의 해결 방안 안내에 따라 조치를 권고

□ 설명
o ERS DataServer 및 ERS ReportingServer 엔진(JavaViewer)에서 발생하는 악의적인 파일 업로드 및 실행 가능 취약점 [1][2]

□ 영향을 받는 제품

제조사 / 제품명 / 영향받는 버전 / 해결 방안
엠투소프트 / ERS DataServer / 6.4.5.494 이하 / 6.4.5.495 이상 (최신 버전 : 6.4.5.506)
엠투소프트 / ERS DataServer / 7.4.4.684 이하 / 7.4.4.685 이상 (최신 버전 : 7.4.4.707)
엠투소프트 / ERS DataServer / 8.2.2.328 이하 / 8.2.2.329 이상 (최신 버전 : 8.2.2.359)
엠투소프트 / ERS ReportingServer 엔진(JavaViewer) / CROWNIX Report&ERS 6 - Java Engine Version : 5.x 이상 5.5.14.1070 이하 / CROWNIX Report&ERS 6 - Java Engine Version : 5.5.14.1071 이상 (최신 버전 : 5.5.14.1108)
엠투소프트 / ERS ReportingServer 엔진(JavaViewer) / CROWNIX Report&ERS 7 - Java Engine Version : 7.x 이상 7.4.3.960 이하 / CROWNIX Report&ERS 7 - Java Engine Version : 7.4.3.961 이상 (최신 버전 : 7.4.3.1109)
엠투소프트 / ERS ReportingServer 엔진(JavaViewer) / CROWNIX Report&ERS 8 - Java Engine Version : 8.x 이상 8.2.0.345 이하 / CROWNIX Report&ERS 8 - Java Engine Version : 8.2.0.346 이상 (최신 버전 : 8.2.3.664)

※ 해결 버전은 아래 엠투소프트에 문의 후 설치

□ 조치 방법
(1) 해결 버전으로 업데이트
(2) 아래 조치 추가 적용
o ERS DataServer
(1) 디렉토리 경로 변경
./DataServer/manager → ./DataServer/WEB-INF/manager
./DataServer/formmanager → ./DataServer/WEB-INF/formmanager
(2) 라이브러리 패치
최신 버전 라이브러리 파일(ers-data-core.jar 등)을 받아 ./DataServer/WEB-INF/lib 경로에 배치 (덮어쓰기)
(3) 제거
./DataServer/uploadf.jsp
o ERS ReportingServer 엔진(JavaViewer)
(1) 디렉토리 경로 변경
./ReportingServer/manager → ./ReportingServer/WEB-INF/manager
(2) 라이브러리 패치
최신 버전 라이브러리 파일(javard.jar 등)을 받아 ./ReportingServer/WEB-INF/lib 경로에 배치 (덮어쓰기)
