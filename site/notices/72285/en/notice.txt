Title:
M2Soft Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "M2Soft Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o M2Soft announces a security update addressing vulnerabilities in its products [1] [2]
o Users with lower versions are advised to act according to the manufacturer's resolution guidance

□ Description
o Malicious file upload and executability vulnerability in ers DataServer and ers ReportingServer Engine (JavaViewer) [1] [2]

□ Affected products

□ Remediation steps
(1) Update to Fixed Version
(2) Apply additional actions below
o ERS DataServer
(1) Change directory path
./DataServer/manager → ./DataServer/WEB-INF/manager
./DataServer/formmanager → ./DataServer/WEB-INF/formmanager
(2) Library patch
Get the latest version library files (ers-data-core.jar, etc.). Deploy to/DataServer/WEB-INF/lib path (overwrite)
(3) Remove
./DataServer/uploadf.jsp
o ers ReportingServer Engine (JavaViewer)
(1) Change directory path
./ReportingServer/manager → ./ReportingServer/WEB-INF/manager
(2) Library patch
Get the latest version library files (javard.jar, etc.). Deploy to/ReportingServer/WEB-INF/lib path (overwrite)
