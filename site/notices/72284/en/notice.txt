Title:
Estige Product Security Measures Advisory

Summary:
We are disseminating today's KISA announcement "Estige Product Security Measures Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Estige recommends action on security vulnerabilities found in its products
o Recommend security measures, such as limiting file upload extensions, according to manufacturer's recommendations for users who are using the product

□ Description
o Unauthorized sign-up and inappropriate file upload vulnerabilities in E-GENE ITSM

□ Affected products and remediation

manufacturers / product name / Affected version / Action plan
Estige / E-GENE ITSM / 7.0 or less / Registration Features and File Upload Extension Restrictions

□ Temporary mitigation before applying the patch
1. Set restrictions on the ability to register
- After temporarily blocking the registration function, new user registration is replaced by manual registration.
2. File upload extension limitations
- Apply whitelist-based verification for the extensions you want to allow
※ For other security measures, apply security patches according to the manufacturer's instructions.
