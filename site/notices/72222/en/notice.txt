Title:
Adobe Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Adobe Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Adobe has released security updates to address vulnerabilities occurring in its products [1]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Out-of-bounds Write vulnerability occurring in Adobe Acrobat, Acrobat Reader, and Acrobat 2024 (CVE-2026-81983) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Resolved Version
CVE-2026-81983 / Acrobat 2024 / 24.001.30383 and earlier / 24.001.30429 and later
CVE-2026-81983 / Acrobat / Less than 26.002.21901 / 26.002.21901 and later
CVE-2026-81983 / Acrobat Reader / Less than 26.002.21901 / 26.002.21901 and later
※ Perform updates by checking the reference sites below [1]

□ Reference sites
[1] https://helpx.adobe.com/security/products/acrobat/apsb26-141.html
[2] https://nvd.nist.gov/vuln/detail/CVE-2026-81983
