제목:
Synology 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Synology 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Synology社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1][2]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o Synology DiskStation Manager(DSM)에서 발생하는 SQL Injection 취약점(CVE-2026-76954) [1][3]
o Synology DiskStation Manager(DSM)에서 발생하는 Authorization Bypass Through User-Controlled Key 취약점(CVE-2026-13672) [2][4]
o Synology DiskStation Manager(DSM)에서 발생하는 Path Traversal 취약점(CVE-2026-18792) [2][5]
o Synology DiskStation Manager(DSM)에서 발생하는 Missing Critical Step in Authentication 취약점(CVE-2026-74857) [2][6]
o Synology DiskStation Manager(DSM)에서 발생하는 Authentication Bypass Using an Alternate Path or Channel 취약점(CVE-2026-85101) [1][7]
o Synology DiskStation Manager(DSM)에서 발생하는 Authentication Bypass Using an Alternate Path or Channel 취약점(CVE-2026-18596) [2][8]
o Synology DiskStation Manager(DSM)에서 발생하는 Link Following 취약점(CVE-2026-19048) [2][9]
o Synology DiskStation Manager(DSM)에서 발생하는 SQL Injection 취약점(CVE-2026-81584) [2][10]
o Synology DiskStation Manager(DSM)에서 발생하는 Access of Uninitialized Pointer 취약점(CVE-2026-18633) [2][11]
o Synology DiskStation Manager(DSM)에서 발생하는 OS Command Injection 취약점(CVE-2026-75785) [2][12]
