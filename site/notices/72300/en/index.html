Title:
Synology Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Synology Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o Synology announces security updates that address vulnerabilities in its products [1][2]
o Users using the affected version are advised to update to the latest version as per the resolution.
□ Description
o SQL Injection vulnerability occurring in Synology DiskStation Manager (DSM) (CVE-2026-76954) [1][3]
o Authorization Bypass Through User-Controlled Key vulnerability in Synology DiskStation Manager (DSM) (CVE-2026-13672) [2][4]
o Path Traversal vulnerability in Synology DiskStation Manager (DSM) (CVE-2026-18792) [2][5]
o Missing Critical Step in Authentication vulnerability occurring in Synology DiskStation Manager (DSM)CVE-2026-74857) [2][6]
o Authentication Bypass Using an Alternate Path or Channel vulnerability in Synology DiskStation Manager (DSM)CVE-2026-85101) [1][7]
o Authentication Bypass Using an Alternate Path or Channel vulnerability in Synology DiskStation Manager (DSM)CVE-2026-18596) [2][8]
o Link Following vulnerability in Synology DiskStation Manager (DSM) (CVE-2026-19048) [2][9]
o SQL Injection vulnerability occurring in Synology DiskStation Manager (DSM) (CVE-2026-81584) [2][10]
o Access of Uninitialized Pointer vulnerability in Synology DiskStation Manager (DSM) (CVE-2026-18633) [2][11]
o OS Command Injection vulnerability occurring in Synology DiskStation Manager (DSM) (CVE-2026-75785) [2][12]
