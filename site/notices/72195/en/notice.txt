Title:
Linux Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Linux Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o The Linux Foundation announces security updates that address vulnerabilities in its products. [1]~[3]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Improper Check for Unusual or Exceptional Conditions vulnerability in Linux kernel (CVE-2025-39682) [1][4]
o Race Condition Vulnerability in Linux Kernel (CVE-2025-39964) [2][5]
o Out-of-bounds Write vulnerability in Linux kernel (CVE-2026-53266) [3][6]
