Title:
GitLab Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "GitLab Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o GitLab released security updates to resolve vulnerabilities in their products [1][2]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Integer Overflow or Wraparound vulnerability in GitLab CE/EE(CVE-2026-97229) [1][3]
o Cross-site Scripting vulnerability in GitLab CE/EE(CVE-2026-92883) [1][4]
o Incorrect Authorization vulnerability in GitLab CE/EE(CVE-2026-16301) [1][5]
o Permissive Regular Expression vulnerability in GitLab CE/EE(CVE-2026-14814) [1][6]
o Improper Neutralization of Special Elements Used in a Template Engine vulnerability in GitLab AI Gateway(CVE-2026-90970) [2][7]
