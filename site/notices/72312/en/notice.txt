Title:
Citrix Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Citrix Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Citrix has released security updates to address vulnerabilities in its products [1]~[3]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-120868) [1][4]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-107407) [1][5]
o Out-of-bounds Write vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-107408) [1][6]
o Double Free vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-107409) [1][7]
o Heap-based Buffer Overflow vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-107410) [1][8]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-107412) [1][9]
o Heap-based Buffer Overflow vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-107415) [1][10]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-120864) [1][11]
o Improper Authentication vulnerability in NetScaler Console(CVE-2026-120869) [2][12]
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC, NetScaler Gateway(CVE-2026-111334) [1][13]
o Improper Privilege Management vulnerability in Secure Access Client for Windows(CVE-2026-118268) [3][14]
