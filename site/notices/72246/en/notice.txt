Title:
JFrog Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "JFrog Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o JFrog announces a security update that addresses vulnerabilities in its products. [1]
o Users running affected versions are advised to update to the latest version according to the workaround.

□ Description
o Improper Authentication Vulnerability in JFrog Artifactory (CVE-2026-82329) [1][2]
