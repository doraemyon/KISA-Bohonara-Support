Title:
Oracle Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Oracle Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Oracle releases security updates to address vulnerabilities in its products [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Out-of-bounds Write Vulnerability in OpenJDK's Base64 Decoder (CVE-2026-114938) [1][2]
