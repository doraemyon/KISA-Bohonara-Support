Title:
Adobe Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Adobe Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Adobe announces security updates that address vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Improper Neutralization of Special Elements Used in a Template Engine vulnerability occurring in Adobe Commerce, Adobe Commerce B2B, and Magento Open Source (CVE-2026-75650) [1][2]
