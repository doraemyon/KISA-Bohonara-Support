제목:
Adobe 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Adobe 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Adobe社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1][2]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o Adobe Commerce, Adobe Commerce B2B, Magento Open Source, Adobe Commerce Events에서 발생하는 Unrestricted Upload of File with Dangerous Type 취약점(CVE-2026-48356) [1][3]
o Adobe Connect에서 발생하는 Code Injection 취약점(CVE-2026-48360) [2][4]
