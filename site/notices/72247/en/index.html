Title:
Adobe Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Adobe Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o Adobe releases security updates to address vulnerabilities in its products [1][2]
o Users running affected versions are advised to update to the latest version according to the workaround.
□ Description
o Unrestricted Upload of File with Dangerous Type vulnerability in Adobe Commerce, Adobe Commerce B2B, Magento Open Source, and Adobe Commerce Events (CVE-2026-48356) [1][3]
o Code Injection Vulnerability in Adobe Connect (CVE-2026-48360) [2][4]
