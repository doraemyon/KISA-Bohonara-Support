제목:
OpenSSH 보안 업데이트 권고

요약:
금일 KISA 공지 "OpenSSH 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o Alpine Linux는 OpenSSH에서 발생하는 인증 우회 취약점을 해결한 보안 업데이트 발표
o 영향받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 신속히 업데이트 권고

□ 설명
o OpenSSH에서 비밀번호 처리 오류로 인해 발생하는 인증 우회 취약점(CVE-2026-123158)
※ musl C 라이브러리 기반이며 PAM을 사용하지 않는 리눅스 환경(Alpine Linux 기본 설정 등)에서 비밀번호 인증이 활성화된 경우에 해당
※ glibc 기반 리눅스 배포판(RHEL, Ubuntu, Debian 등) 및 PAM 사용 환경(UsePAM yes)은 영향 없음
