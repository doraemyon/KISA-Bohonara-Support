Title:
OpenSSH Security Update Advisory

Summary:
We are disseminating today's KISA announcement "OpenSSH Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Alpine Linux announces a security update that resolves an authentication bypass vulnerability in OpenSSH
o Users with affected versions are advised to update to the latest version as soon as possible in accordance with the resolution

□ Description
o Authentication Bypass Vulnerability Due to Password Processing Error in OpenSSH (CVE-2026-123158)
※ Applicable if password authentication is enabled in a Linux environment (such as Alpine Linux default settings) that is based on the musl C library and does not use Pam
※ Glibc-based Linux distributions (RHEL, Ubuntu, Debian, etc.) and Pam-enabled environments (UsePAM yes) are not affected
