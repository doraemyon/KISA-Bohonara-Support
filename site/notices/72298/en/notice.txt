Title:
React server component security update advisory

Summary:
We are disseminating today's KISA announcement "React server component security update advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Announcement of security update that resolves vulnerabilities in React’s server component [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Deserialization of Untrusted Data vulnerability occurring in React Server Components (CVE-2026-126187) [1][2]
