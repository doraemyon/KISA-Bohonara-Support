Title:
Oracle Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Oracle Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Oracle has released security updates to address vulnerabilities occurring in its products [1][2]
o Users utilizing affected versions are recommended to update to the latest version according to the mitigation measures

□ Description
o Use of a Broken or Risky Cryptographic Algorithm vulnerability occurring in Oracle Java SE, Oracle GraalVM for JDK, Oracle GraalVM Enterprise Edition, OpenJDK (CVE-2026-91403) [1][2][3]
