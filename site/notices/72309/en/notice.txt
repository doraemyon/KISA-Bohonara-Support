Title:
MongoDB Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "MongoDB Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o MongoDB releases a security update to address vulnerabilities in its products [1][2]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Incorrect Behavior Order: Validate Before Canonicalize vulnerability in Node.js Driver (CVE-2026-126837) [1]~[3]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-126837 / Node.js Driver / 3.3.3 or later and below 7.8.0 / 7.8.0 or later
※ Perform updates by referring to the sites listed below. [1][2]
