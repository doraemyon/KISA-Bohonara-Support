Title:
ConnectWise Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "ConnectWise Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o ConnectWise releases a security update to address vulnerabilities in its products. [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Missing Authorization Vulnerability in ConnectWise ScreenConnect (CVE-2026-84869) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-84869 / ScreenConnect / Below 26.6.5 / 26.6.5 or later
※ Perform updates by referring to the sites listed below. [1]
