Title:
Langflow Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Langflow Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o IBM has released security updates to address vulnerabilities occurring in its products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Missing Authentication for Critical Function vulnerability in Langflow OSS (CVE-2026-8446) [1][2]
o Reliance on Untrusted Inputs in a Security Decision vulnerability in Langflow OSS (CVE-2026-9077) [1][3]
o OS Command Injection vulnerability in Langflow OSS (CVE-2026-17623) [1][4]
o OS Command Injection vulnerability in Langflow OSS (CVE-2026-17625) [1][5]
o Incorrect Privilege Assignment vulnerability in Langflow OSS (CVE-2026-17626) [1][6]
o Incomplete List of Disallowed Inputs vulnerability in Langflow OSS (CVE-2026-17630) [1][7]
