Title:
Apache Product Security Update Advisory
Summary:
We are disseminating today's KISA announcement "Apache Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.
Body:
□ Overview
o The Apache Foundation released security updates to address vulnerabilities occurring in its products [1]~[10]
o Users running affected versions are advised to update to the latest version according to the mitigation instructions
□ Description
o Improper Authentication vulnerability in Apache Tomcat(CVE-2026-75973) [1][11]
o Authentication Bypass by Alternate Name vulnerability in Apache Tomcat(CVE-2026-76183) [2][12]
o Race Condition vulnerability in Apache Tomcat(CVE-2026-77762) [3][13]
o Incomplete Cleanup vulnerability in Apache Tomcat(CVE-2026-78437) [4][14]
o HTTP Request/Response Smuggling vulnerability in Apache Tomcat(CVE-2026-86350) [5][15]
o Uncontrolled Resource Consumption vulnerability in Apache Tomcat(CVE-2026-77791) [6][16]
o Improper Handling of Length Parameter Inconsistency vulnerability in Apache Tomcat(CVE-2026-87022) [7][17]
o Allocation of Resources Without Limits or Throttling vulnerability in Apache Tomcat(CVE-2026-78383) [8][18]
o Missing Release of Resource after Effective Lifetime vulnerability in Apache Tomcat(CVE-2026-79677) [9][19]
o Improper Authentication vulnerability in Apache Tomcat(CVE-2026-86248) [10][20]
