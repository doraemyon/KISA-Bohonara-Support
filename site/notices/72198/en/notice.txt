Title:
Check Point Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Check Point Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Check Point has released security updates to address vulnerabilities occurring in its products [1]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Path Traversal vulnerability occurring in Check Point Security Management Server, Multi-Domain Security Management Server, Log Server, Multi-Domain Log Server, and SmartEvent (CVE-2026-93616) [1][2]
