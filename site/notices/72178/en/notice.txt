Title:
Metabase Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Metabase Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Metabase has released security updates to address vulnerabilities occurring in its products [1][2][3][4]
o Users utilizing affected versions are advised to update to the latest version according to the mitigation measures
o Recent attacks and damages resulting from these vulnerabilities have been reported, requiring user caution

□ Description
o SQL Injection vulnerability occurring in Metabase(CVE-2026-72898) [1][5]
o SQL Injection vulnerability occurring in Metabase(CVE-2026-72899) [2][6]
o Missing Authorization vulnerability occurring in Metabase(CVE-2026-72900) [3][7]
