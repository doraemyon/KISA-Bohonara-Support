Title:
Cisco Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Cisco Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Cisco releases security updates to address vulnerabilities in its products [1]~[3]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Improper Control of a Resource Through its Lifetime vulnerability in Cisco IOS XR Software (CVE-2026-20274) [1][4]
o Incorrect Calculation Vulnerability in Cisco IOS XR Software (CVE-2026-20275) [1][5]
o Insufficient Control Flow Management Vulnerability in Cisco IOS XR Software (CVE-2026-20276) [1][6]
o Protection Mechanism Failure Vulnerability in Cisco IOS XR Software (CVE-2026-20277) [1][7]
o Improper Neutralization Vulnerability in Cisco IOS XR Software (CVE-2026-20278) [1][8]
o Improper Access Control Vulnerability in Cisco IOS XR Software (CVE-2026-20279) [1][9]
o Improper Check or Handling of Exceptional Conditions vulnerability in Cisco IOS XR Software (CVE-2026-20280) [1][10]
o Improper Restriction of XML External Entity Reference Vulnerability in Cisco BroadWorks (CVE-2026-20320) [2][11]
o Classic Buffer Overflow Vulnerability in ClamAV and Cisco Secure Endpoint Connector (CVE-2026-20337) [3][12]
o Double Free Vulnerability in ClamAV and Cisco Secure Endpoint Connector (CVE-2026-20338) [3][13]
o Integer Overflow or Wraparound Vulnerability in ClamAV and Cisco Secure Endpoint Connector (CVE-2026-20339) [3][14]
o Stack-based Buffer Overflow Vulnerability in ClamAV and Cisco Secure Endpoint Connector (CVE-2026-20345) [3][15]
o Out-of-bounds Read Vulnerability in ClamAV and Cisco Secure Endpoint Connector (CVE-2026-20346) [3][16]
