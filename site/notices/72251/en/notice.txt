Title:
Synology Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Synology Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Synology releases security updates to address vulnerabilities in its products [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Use-After-Free Vulnerability in Synology Calendar, Mail Station, and PHP (CVE-2026-109618) [1][2]
o Use-After-Free Vulnerability in Synology Calendar, Mail Station, and PHP (CVE-2026-109619) [1][3]
