Title:
Citrix Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Citrix Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Citrix releases security updates to address vulnerabilities in its products [1]
o Users running an affected version are advised to update to the latest version according to the workaround.

□ Description
o Improper Restriction of Operations within the Bounds of a Memory Buffer vulnerability in NetScaler ADC and NetScaler Gateway (CVE-2026-88779) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-88779 / NetScaler ADC / Below 13.1-64.28 / 13.1-64.28 or later
CVE-2026-88779 / NetScaler ADC / Below 14.1-73.41 / 14.1-73.41 or later
CVE-2026-88779 / NetScaler Gateway / Below 13.1-64.28 / 13.1-64.28 or later
CVE-2026-88779 / NetScaler Gateway / Below 14.1-73.41 / 14.1-73.41 or later
CVE-2026-88779 / NetScaler ADC FIPS/NDcPP / Below 13.1-37.282 / 13.1-37.282 or later
CVE-2026-88779 / NetScaler ADC FIPS / 14.1-73.41 Below FIPS / 14.1-73.41 FIPS or higher
