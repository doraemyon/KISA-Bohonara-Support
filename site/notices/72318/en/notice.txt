Title:
PHP Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "PHP Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o The PHP Group releases security updates that address vulnerabilities in its products [1][2][3][4]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Improper Input Validation, Deserialization of Untrusted Data vulnerabilities occurring in PHP (CVE-2026-115560) [1][5]
o Time-of-check Time-of-use (TOCTOU) Race Condition, Improper Synchronization vulnerability that occurs in PHP (CVE-2026-126714) [1][6]
o Use After Free, Incomplete Cleanup vulnerabilities occurring in PHP (CVE-2026-129182) [1][7]
o HTTP Request Smuggling, Always-Incorrect Control Flow Implementation vulnerabilities occurring in PHP (CVE-2026-129289) [1][8]
o Use After Free Vulnerability in PHP (CVE-2026-129474) [1][9]
o Use After Free, Incomplete Cleanup vulnerabilities occurring in PHP (CVE-2026-129481) [1][10]
o Use After Free, Incomplete Cleanup vulnerabilities occurring in PHP (CVE-2026-129496) [1][11]
o Uncontrolled Resource Consumption, Inefficient Algorithmic Complexity vulnerabilities occurring in PHP (CVE-2026-127960) [1][12]
o Cleartext Transmission of Sensitive Information vulnerability in PHP (CVE-2026-128064) [1][13]
o Improper Verification of Cryptographic Signature, Algorithm Downgrade vulnerability occurring in PHP (CVE-2026-128090) [1][14]
o Use After Free Vulnerability in PHP (CVE-2026-129291) [1][15]
o Cross-site scripting vulnerability occurring in PHP (CVE-2026-129292) [1][16]
o Integer Overflow or Wraparound, Unchecked Return Value vulnerabilities that occur in PHP (CVE-2026-129438) [1][17]
o Double Free, Use After Free Vulnerabilities in PHP (CVE-2026-129501) [1][18]
o Use After Free Vulnerability in PHP (CVE-2026-129506) [1][19]
o Out-of-bounds Read, Out-of-bounds Write, Use of Out-of-range Pointer Offset vulnerabilities occurring in PHP (CVE-2026-129538) [1][20]
o Out-of-bounds Read, Use of Uninitialized Resource vulnerability in PHP (CVE-2026-15353) [1][21]
o Integer Overflow or Wraparound vulnerability occurring in PHP (CVE-2026-48841) [1][22]
