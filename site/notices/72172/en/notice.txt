Title:
Oracle Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Oracle Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Oracle has released security updates to resolve vulnerabilities occurring in its products [1]
o Users utilizing affected versions are recommended to update to the latest version according to the mitigation measures

□ Description
o Missing Authentication for Critical Function vulnerability occurring in Oracle WebLogic Server (CVE-2026-60672) [1][2]
o Missing Authentication for Critical Function vulnerability occurring in Oracle WebLogic Server (CVE-2026-60696) [1][3]
o Missing Authentication for Critical Function vulnerability occurring in Oracle WebLogic Server (CVE-2026-60698) [1][4]
