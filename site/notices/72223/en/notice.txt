Title:
Plex Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Plex Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Plex released security updates to address vulnerabilities occurring in its products [1]
o Users running affected versions are advised to update to the latest version according to the mitigation measures

□ Description
o Path Traversal vulnerability in Plex Media Server(CVE-2026-96651) [1][2]
o SSRF vulnerability in Plex Media Server(CVE-2026-96652) [1][3]
o Improper Neutralization of Encoded URI Schemes in a Web Page vulnerability in Plex Media Server(CVE-2026-96654) [1][4]
o SSRF vulnerability in Plex Media Server(CVE-2026-96655) [1][5]
o External Control of File Name or Path vulnerability in Plex Media Server(CVE-2026-96656) [1][6]
