Title:
Node.js Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Node.js Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o The OpenJS Foundation has announced a security update that addresses vulnerabilities in its products. [1]~[3]
o Users running affected versions are advised to update to the latest version according to the workaround.

□ Description
o Reachable Assertion Vulnerability in Node.js (CVE-2026-123863) [1][4]
o Race Condition Vulnerability in Node.js (CVE-2024-27983) [2][5]
o Use-After-Free Vulnerability in Node.js (CVE-2026-123864) [1][6]
o Uncontrolled Resource Consumption Vulnerability in Node.js (CVE-2026-123865) [1][7]
o Uncontrolled Resource Consumption Vulnerability in Node.js (CVE-2026-48937) [3][8]
o Use-After-Free Vulnerability in Node.js (CVE-2026-123866) [1][9]
o NULL Pointer Dereference vulnerability in Node.js (CVE-2026-126051) [1][10]
o Improper Authentication Vulnerability in Node.js (CVE-2026-123872) [1][11]
o Use-After-Free Vulnerability in Node.js (CVE-2026-123874) [1][12]
o Exposure of Private Personal Information to an Unauthorized Actor vulnerability in Node.js (CVE-2026-48615) [3][13]
