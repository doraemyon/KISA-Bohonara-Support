제목:
Node.js 제품 보안 업데이트 권고

요약:
금일 KISA 공지 "Node.js 제품 보안 업데이트 권고" 전파드리오니, 영향 버전을 가용중인 각 관계사 담당자 분들께 업데이트 권고 드리며 특이사항 있으시면 회신 바랍니다.

본문:
□ 개요
o OpenJS 재단은 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[3]
o 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

□ 설명
o Node.js에서 발생하는 Reachable Assertion 취약점(CVE-2026-123863) [1][4]
o Node.js에서 발생하는 Race Condition 취약점(CVE-2024-27983) [2][5]
o Node.js에서 발생하는 Use After Free 취약점(CVE-2026-123864) [1][6]
o Node.js에서 발생하는 Uncontrolled Resource Consumption 취약점(CVE-2026-123865) [1][7]
o Node.js에서 발생하는 Uncontrolled Resource Consumption 취약점(CVE-2026-48937) [3][8]
o Node.js에서 발생하는 Use After Free 취약점(CVE-2026-123866) [1][9]
o Node.js에서 발생하는 NULL Pointer Dereference 취약점(CVE-2026-126051) [1][10]
o Node.js에서 발생하는 Improper Authentication 취약점(CVE-2026-123872) [1][11]
o Node.js에서 발생하는 Use After Free 취약점(CVE-2026-123874) [1][12]
o Node.js에서 발생하는 Exposure of Private Personal Information to an Unauthorized Actor 취약점(CVE-2026-48615) [3][13]
