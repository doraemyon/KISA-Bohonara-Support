Title:
Fortinet Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "Fortinet Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o Fortinet announces security update that addresses vulnerabilities in its products [1]~[3]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Improper Authentication Vulnerability Occurring in FortiWeb (CVE-2026-26035) [1][4]
o Classic Buffer Overflow Vulnerability in FortiClientWindows (CVE-2026-70465) [2][5]
o Authentication Bypass Using an Alternate Path or Channel vulnerability occurring in FortiManager and FortiManager Cloud (CVE-2026-70468) [3][6]
