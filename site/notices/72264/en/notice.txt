Title:
TeamViewer Product Security Update Advisory

Summary:
We are disseminating today's KISA announcement "TeamViewer Product Security Update Advisory". We recommend that representatives at each affiliated company using an affected version update, and please reply if you have any specific issues.

Body:
□ Overview
o TeamViewer announces security update that addresses vulnerabilities in its products [1]
o Users using the affected version are advised to update to the latest version as per the resolution.

□ Description
o Integer Overflow or Wraparound vulnerability occurring in TeamViewer Full Client, Portable, and Remote Control App (CVE-2026-111585) [1][2]

□ Affected Products and Solutions
Vulnerability / Product Name / Affected Version / Fixed Version
CVE-2026-111585 / Full Client Legacy/Maintenance (Windows) / 13.2 / 13.2.36231 or later
CVE-2026-111585 / Full Client Legacy/Maintenance (macOS) / 13.2 / 13.2.154007 or later
CVE-2026-111585 / Full Client Legacy/Maintenance (Linux) / 13.2 / 13.2.154008 or later
CVE-2026-111585 / Full Client Legacy/Maintenance (Windows, Linux, macOS) / 14.7 / 14.7.48868 or later
CVE-2026-111585 / Full Client Legacy/Maintenance (Windows 7 & 8) / 15.64 / 15.64.10 or later
CVE-2026-111585 / Full Client (Windows, Linux, macOS) / Below 15.83 / 15.83 or later
CVE-2026-111585 / Portable (Windows) / Below 15.83 / 15.83 or later
